====================================================
WIRING NOTES - TRANSPORT ROBOT "SAMIR-KAHWEJI"
NEXUS-TN Project
====================================================

NOTE: This subsystem does NOT use a custom PCB. The wiring is simple
enough to be done directly with the components below, without a
dedicated control board design.

--------------------------------------------------
1. MAIN CONTROL BOARD
--------------------------------------------------

Microcontroller: ESP32
  -> Central control board for the transport robot

--------------------------------------------------
2. DRIVE / MOTOR SYSTEM
--------------------------------------------------

4x IBT motor drivers -> connected to the ESP32
  -> Each IBT driver controls one drive motor

--------------------------------------------------
3. SERVO SYSTEM
--------------------------------------------------

1x PWM servo expansion board -> connected to the ESP32
  -> Controls 3 servos total:
       a) 1 servo -> wheel configuration transformation mechanism
          (6-wheel to 4-wheel folding)
       b) 2 servos -> camera support (2 degrees of freedom, for
          line-following / obstacle detection)

--------------------------------------------------
4. CAMERA / VISION SYSTEM
--------------------------------------------------

Raspberry Pi 5 -> connected to the onboard camera
  -> Handles camera processing (line-following detection, obstacle
     detection)
  -> Powered by its OWN dedicated power bank (fully separate from the
     motor/servo power supply)

--------------------------------------------------
5. POWER SUPPLY ARCHITECTURE
--------------------------------------------------

Power is split into 3 fully separate supplies:

  a) LiPo 3S -> Navigation system
       Powers: the 4 drive motors (via the 4 IBT drivers)

  b) LiPo 2S -> Servo + control system
       Powers: the ESP32 control board AND the 3 servos
       (via the PWM servo expansion board)

  c) Power Bank -> Vision system
       Powers: the Raspberry Pi 5 + camera ONLY

Reason for separate supplies:
- Isolates the noisy/high-current drive motors from the sensitive
  control and vision electronics
- Prevents voltage drops/noise from the motors affecting the
  Raspberry Pi 5 or the ESP32
- Makes it easier to service or swap one power source without
  affecting the others

--------------------------------------------------
6. GENERAL WIRING NOTES
--------------------------------------------------

- Keep a COMMON GROUND between the ESP32, the 4 IBT drivers, and the
  PWM servo expansion board (even though their positive rails are
  separate, when applicable).
- The Raspberry Pi 5 + camera system remains ELECTRICALLY ISOLATED
  on its own power bank (no shared ground required, unless a direct
  data connection to the ESP32 requires it).
- Confirm LiPo 3S and 2S voltage/balance before powering the
  respective systems.
